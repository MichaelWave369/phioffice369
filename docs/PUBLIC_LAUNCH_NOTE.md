# Public Launch Note Draft

Introducing **PhiOffice369** — a free, local-first, AI-assisted sovereign productivity suite concept from PHI369 Labs / Parallax.

The goal is simple: help people write, calculate, present, organize, map, publish, and transform their work without subscription traps, forced cloud accounts, or unclear AI behavior.

This repo starts as the public planning and prototype home for the project.

Early focus:

- PhiWrite-lite
- PhiGrid-lite
- PhiDeck-lite
- Template packs
- Professor Phi assistant panel
- Trust labels for human/AI/sourced/symbolic/private content
- Local-first project folders
- Honest compatibility reports

Built for families, students, creators, small businesses, community groups, and sovereign builders.
