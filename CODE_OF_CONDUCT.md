# Code of Conduct

PhiOffice369 is intended to be useful, kind, and accessible.

Participants are expected to:

- Treat others with respect.
- Avoid harassment, insults, and personal attacks.
- Assume good faith when possible.
- Keep criticism specific and constructive.
- Help make the project welcoming to beginners and non-traditional builders.

The goal is to build tools that help people create, learn, organize, and flourish.
