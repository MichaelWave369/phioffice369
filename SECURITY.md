# Security Policy

PhiOffice369 is early-stage. Please do not use it for sensitive production workflows until a security review has been completed.

## Reporting issues

For now, open a GitHub issue for non-sensitive bugs.

For sensitive security issues, contact the maintainer privately before public disclosure.

## Security principles

- Local-first by default
- No hidden upload behavior
- No forced account creation
- Clear disclosure when online services are used
- Minimal permissions
- User-controlled export and deletion
