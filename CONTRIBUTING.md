# Contributing

Thank you for your interest in PhiOffice369.

## Contribution principles

- Keep the project local-first where possible.
- Do not add forced-cloud behavior.
- Do not hide AI usage from users.
- Do not overpromise compatibility.
- Respect user privacy.
- Keep public claims honest and testable.
- Preserve the warm, useful, human-centered identity of the suite.

## Good first contributions

- Documentation improvements
- Template packs
- Accessibility improvements
- UI mockups
- Local-first storage experiments
- Import/export experiments with compatibility reports
- Trust-panel UX ideas

## Pull request checklist

Before opening a pull request, confirm:

- The change does not imply affiliation with third-party office-suite vendors.
- Any new dependency has a compatible license.
- AI-related behavior is visible and controllable.
- User data remains local unless clearly disclosed.
- Documentation is updated when behavior changes.
