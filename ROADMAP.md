# PhiOffice369 Roadmap

## v0.1 — Identity MVP

Goal: prove the identity, local-first feel, and artifact workflow without overpromising full office-suite compatibility.

### Build targets

- Launcher shell
- Recent files and project folders
- PhiWrite-lite editor
- PhiGrid-lite table/spreadsheet editor
- PhiDeck-lite slide/poster builder
- Template library
- Professor Phi assistant panel
- Trust panel labels
- Local-only privacy mode
- Export: Markdown, HTML, PDF/image where feasible
- Import/export: CSV and JSON for structured artifacts

### Definition of done

- A user can create a project folder.
- A user can create a simple doc, grid, and deck.
- A user can transform a doc outline into a deck draft.
- A user can label content using trust-panel categories.
- The app does not require a cloud account.
- The README clearly states compatibility limits.
