# Suite Modules

## PhiWrite

Document editor for specs, letters, reports, books, PDFs, and structured writing.

## PhiGrid

Spreadsheet and atlas tool for budgets, formulas, ledgers, trackers, catalogs, and lightweight databases.

## PhiDeck

Slide, poster, pitch, and presentation builder.

## PhiNotes

Research notebooks, meeting notes, idea gardens, source maps, and linked pages.

## PhiMap

Diagrams, flowcharts, architecture maps, system maps, and dependency views.

## PhiPress

Flyers, zines, worksheets, print sheets, and simple publishing layouts.

## PhiBase

Local database builder for simple records, inventory, contacts, card catalogs, dashboards, and forms.

## PhiVault

Local file vault, project folders, tags, search, receipts, artifact lineage, and optional future sync.

## PhiFlow

Tasks, calendar/reminders, project checklists, workflow bridge, and optional email/calendar integrations.

## Professor Phi

Assistant, editor, workflow helper, transformer, template generator, explainer, and claim-checker.
